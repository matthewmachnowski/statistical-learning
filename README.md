# An Introduction to Statistical Learning

This repository contains my personal learning materials for "An Introduction to Statistical Learning: with Applications in Python" by Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani, and Jonathan Taylor.

## About

This repository contains the notebooks from the original site with the labs for each chapter.

This is my dedicated learning space for working through the book and practicing statistical learning concepts. The repository includes:
- Jupyter notebooks with lab exercises
- Datasets used in examples and exercises  
- Personal notes and solutions

For complete book details, resources, and official materials, visit [statlearning.com](https://www.statlearning.com).
