# An Introduction to Statistical Learning

Personal learning materials for *An Introduction to Statistical Learning: with Applications in Python* by Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani, and Jonathan Taylor.

For official resources visit [statlearning.com](https://www.statlearning.com).

---

## Installation

```bash
pip install -r requirements.txt
```

---

## Repository Structure

Each chapter has its own folder containing:
- `ChXX-lab.ipynb` — lab notebook from the [ISLP GitHub](https://github.com/intro-stat-learning/ISLP_labs), added after finishing the chapter
- `ChXX-exercises.ipynb` — personal solutions to the Conceptual and Applied exercises at the end of the chapter
